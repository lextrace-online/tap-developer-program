CO JE TAP? // program.init()

Microsoft 365 Technology Adoption Program (TAP) je exkluzivní program určený pro ISV partnery (Independent Software Vendors), kteří vyvíjejí multi-tenant řešení integrující se s Microsoft 365. TAP je přímá linka do produktových týmů Microsoftu — umožňuje přístup k roadmapám, privátním preview funkcím a přímé zpětné vazbě ještě před obecnou dostupností.
